# Code of conduct

Treat contributors and users with respect. Discuss code and ideas on their
merits; make feedback specific and useful. Welcome people of different
backgrounds and experience levels.

Harassment, discrimination, threats, sexualized conduct, and publication of
someone else's private information are not acceptable in project spaces.

Maintainers may edit or remove contributions, close discussions, or restrict
participation when conduct harms the community. They will consider context and
apply these expectations consistently.

Report concerns privately through contact information on a repository maintainer's
GitHub profile. If no private route exists, ask for one without posting sensitive
details in an issue. Reports will be handled with care for the people involved.
