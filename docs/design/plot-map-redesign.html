Redesigning the 2D X/Y and map plots

Interactive mockups built from the Forest theme tokens. Each demo has a Proposed view you can poke at (hover, drag, scrub the timeline, toggle legend rows) and a Current view reconstructed from plot_actions.rs, mapping/toolbar.rs, mapping/settings.rs and trajectory_axes.rs. Flight data is synthetic, placed at the PX4 SITL home (47.3977 N, 8.5456 E).

Today

  • Header is seven text buttons wide. On a half-width dock it wraps or truncates before the plot gets room.
  • Legend names are full topic/0/x vs topic/0/y strings, so the legend covers the path.
  • No start, end or direction cues. A loop and its return leg look identical.
  • Axes scale independently, so a circle flown in metres draws as an ellipse.

Proposed

  • Icon header with tooltips. Rare actions go under ⋯.
  • Links pill shows active links as text; click for checkboxes.
  • 1:1 aspect on by default for spatial pairs with equal units.
  • Direction chevrons, start ▲ and end ■ markers on every trace.
  • Legend top right with short names (topic + axes) and the unit as metadata. Click a row to hide it.
  • Pinned readout for the timeline cursor (t, x, y, speed) and a hover chip that snaps to the nearest sample.

Today

  • Three control rows (pane header, map toolbar, view options) stack above the map and take about 70 px.
  • The same jobs show up twice: 2D/3D, Fit / Fit traces, Follow / Link timeline, Reset view / Reset orbit, split between the toolbar and the builder sidebar.
  • Basemap, offline mode and attribution are only in the builder, so switching to satellite means opening setup.
  • Gradient coloring has no on-map key, so you can't read speed or altitude from the colors.

Proposed

  • The map takes the whole pane. Controls float in the corners, like map apps already do.
  • Top left: Map/3D switch and a layers popover (basemap, ground path, exaggeration, offline).
  • Bottom right: zoom, a compass that rotates with bearing (click for north-up), Fit, and Follow.
  • Top right: legend with an inline gradient key and its min/max.
  • Bottom: scale bar plus required attribution, always visible.
  • Time range link (Links pill): dims the path outside the X bounds of linked time plots. Zoom the speed plot below and the map, profile and arrows follow.
  • Measure (M): two clicks give distance and bearing. Clicks snap to samples; with both ends on samples it shows 3D distance plus its horizontal and vertical parts, and two samples on one trace add Δt, distance flown and average speed. Works in 3D on samples.
  • Altitude profile under 2D maps (toggle in layers): AMSL and terrain against distance flown, hover-linked to the map.
  • Legend quick settings: eye toggles visibility; clicking a name opens color-by and Fit to trace without opening setup.
  • Direction arrows along every trace in 2D and 3D, spaced by screen distance so they stay readable at any zoom.
  • Flight mode changes marked on the path (from the same state mappings as time-plot bands). Hover shows the mode too.
  • Show path: whole flight, flown so far, or last 30 s around the timeline marker, for replaying a flight.
  • The timeline marker is the same heading arrow in 2D and 3D; in 3D a dashed drop line ties it to the ground. Follow keeps it centred in both modes.
  • Hover snaps to a sample and shows time, altitude and speed. Try 3D: drag to orbit.

Today

  • One long column mixes per-trace settings (units, Z, color) with per-map settings (backend, 2D/3D, orbit). It's hard to tell what a button affects.
  • Fix type and Z can be typed as raw field IDs, with separate Bind and Clear buttons.
  • Altitude modes need a paragraph to explain them.
  • Gradient limits need an explicit Apply limits click.

Proposed

  • One collapsible card per trace with a summary line. The open card's trace is highlighted on the map; others dim.
  • Local m opens a Start location section: Default, From GPS (first valid fix of a GPS trace in this map, so local and GPS line up), Click map (crosshair click, live lat/lon readout, pin), or pasted Lat, lon.
  • Put here picks whether the first sample or local (0, 0) lands on the start. The map shows the difference immediately.
  • Saved default start: any start can become the default for new local traces (stored in preferences, beside the theme).
  • NED / ENU axes switch relabels the slots, so x-north logs don't need a manual swap.
  • Unit check: if the data doesn't match the chosen unit, the card turns amber and offers the detected unit in one click.
  • One drop per trace: drop any field from a topic (here or on the map) and its lat/lon/alt or x/y/z siblings fill in, with a note saying what was filled. Try dropping vehicle_gps_position › altitude_msl_m.
  • Color by any field: pick Field and drop e.g. battery_status › voltage_v. The range fills from the data; Auto trims to the 2nd–98th percentile.
  • Slots are drag and drop only, same as the rest of the app: drag from Fields (left) onto a slot, or onto the dashed box to start a new trace.
  • Map-level settings move to the on-map layers popover (Demo 2).
Implementation

Suggested order

Step 1 · small

Icon header + overflow menu

Swap text ActionButtons for icon buttons with tooltips. Move Duplicate, Background, Preset and Units into one DropdownMenu. Shorten the Links trigger to a pill.

plot_actions.rs · plot_links.rs · plot_appearance.rs · style.css
Step 2 · small

Trajectory readability

Start/end markers, direction chevrons every N px of screen-space arc length, 1:1 aspect when both axes share a unit, short legend names.

trajectory_render.rs · trajectory_plot.rs · trajectory.css
Step 3 · medium

On-map control overlay

Merge MapToolbar, MapViewOptions and the map half of the sidebar settings into absolutely positioned clusters inside .trajectory-chart. Drop the duplicate controls.

mapping/toolbar.rs · mapping/view_options.rs · mapping/settings.rs · mapping/scale.rs
Step 4 · medium

Gradient key in legend

Render the color ramp and its limits under any gradient-colored legend row. Reuse the existing color_legend output.

mapping/color_legend.rs · mapping/gradient_legend_row.rs
Step 5 · larger

Trace cards in the builder

Restructure the pair list into cards with summary lines. Replace typed field-ID inputs with drop slots plus a search combobox. Use segmented controls for units and the altitude reference.

trajectory_axes.rs · mapping/settings.rs · mapping/gradient_controls.rs
