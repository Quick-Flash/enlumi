# Profile examples

Start with [Betaflight 2026.6 Explorer pack](betaflight/2026.6/README.md):
52 view choices per logging resolution across rates/PID, RC commands, motors/RPM,
sensors/power, mode/RX bands, and debug.

In Enlumi, **Profiles → Folder…** selects this directory or nested pack directory.
Alternatively copy pack folder into existing library. Preserve `.rs` helpers beside
JSON files. **⋯ → Auto** enables matching defaults without editing recipes.

Older flat examples remain available for small setups and Betaflight 4.5/ULog.
Select matching firmware and resolution; profiles intentionally reject unrelated
logs. Optional channels stay partial. See [profile format](../../docs/PROFILES.md).
