`map-checkerboard.png` is an Enlumi-generated synthetic fixture, licensed under
the repository's AGPL-3.0-or-later license. It contains no geographic imagery.

It is a 256 by 256 RGB PNG. Each 32 by 32 square alternates between RGB
`(34, 58, 78)` and `(49, 86, 102)`, starting with the first color at the top left.
`src/mapping/checker.wgsl` generates the same pattern for GPU surface tests.
